Entry for the [One Line, No Deadline Met](https://make.fun/bounty/u-markk-st-one-line-no-deadline-met-6adc00ce) bounty on make.fun.

## Run

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (or `$ENTRY_OUTPUT_DIR/entry.txt` when set).
The program is Python 3 stdlib only, deterministic, and reads no input.
